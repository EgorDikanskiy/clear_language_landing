# Ясный переводчик

Одностраничный сайт Telegram-бота и браузерного расширения для перевода на ясный язык.

Сайт: https://egordikanskiy.github.io/clear_language_landing/

Статический HTML, CSS и JavaScript без сборки. Для локального просмотра запустите `python3 -m http.server 8000` из корня репозитория.

GitHub Pages публикует корень ветки `main`. Основная страница — `index.html`, фирменные изображения — в `assets/`.
